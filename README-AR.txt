EARTH / JUKEBOX — نسخة تعمل دون إنترنت

1. نزّل الملف المضغوط وفك الضغط عنه بالكامل.
2. افتح المجلد Earth-Jukebox-Offline.
3. افتح index.html باستخدام Chrome أو Edge أو Firefox على الحاسوب.
4. اضغط «ابدأ الاستكشاف». قد يطلب المتصفح نقرة أولى لتفعيل الصوت.

لا تحتاج إلى تثبيت برامج أو تشغيل خادم أو الاتصال بالإنترنت.
احتفظ بملفات المجلد معًا؛ لا تنقل index.html وحده.
الصوت والصور والخطوط ونسخة البيانات مضمّنة محليًا.
روابط المصادر الخارجية وحدها تحتاج إلى الإنترنت عند فتحها.
على الهواتف، قد يقيّد تطبيق فتح الملفات تشغيل المواقع المحلية؛ يُنصح بالحاسوب للعرض.

التجربة: تعليمات افتتاحية واحدة، ثم نغمات منفصلة بلا كلام تلقائي.
مدة النغمة 8 ثوانٍ. التفسير المسموع اختياري. سرعة الراوية 1.25× افتراضيًا.
بيانات NASA GISTEMP v4: 1880–2025؛ النسخة ليست بثًا مباشرًا.
المشروع مستقل ولا يصدر رسميًا عن NASA.
